# Dev Stack Builder

## Description
Dev Stack Builder is a modern, responsive web application designed to help developers explore, compare, and assemble their ideal technology stack across frontend, backend, database, language, and devops tooling with real-time visual feedback.

## Technologies Used
- **React.js (v19)**
- **Vite**
- **Tailwind CSS (v4)**
- **TypeScript**
- **React-Toastify**
- **Lucide React**

## Key Features
1. **Interactive Stack Builder & Duplicate Prevention**: Seamlessly add technologies to your custom stack sidebar with instant duplicate detection, visual button state indicators (`✓ Added to Stack`), individual item deletion (`✕`), and a one-click `Remove All` action.
2. **Real-time Toast Notifications**: Comprehensive alert feedback via `react-toastify` for adding technologies, warning against duplicate additions, and stack modifications.
3. **Dynamic External Data Fetching & Category Filtering**: Asynchronously loads technology data from an external JSON file with an animated loading spinner state and category tabs (Frontend, Backend, Database, Language, Styling, DevOps).
